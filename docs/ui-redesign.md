# 앱 UI 다시 디자인 (Hallmark, 2026-11-28)

[Hallmark](https://github.com/Nutlope/hallmark) v2.0.0의 `redesign` (full, 앱 화면 범위)로 앱 화면 15개를 다시 짰다.
기능·링크·입력칸·핸들러는 그대로이고(전/후 비교 36/36 링크, 10/10 입력칸, 148/148 핸들러), 테스트 29개도 그대로 통과한다.

## 지킨 것과 바꾼 것

| | |
|---|---|
| 그대로 | 잉크 #16181D + 앰버 #F5B323, 로고 글꼴 Black Han Sans, 화면 구성·순서, 모든 문구(아래 3곳 제외) |
| 새로 | 색·간격·글자 크기를 토큰으로(`src/tokens.css`), 본문 글꼴 IBM Plex Sans KR(소개 페이지와 같음), 아이콘(lucide), 버튼 여덟 가지 상태 |
| 대표 장면 | 밴드 카드마다 다음 합주를 **잉크색 표 한 장**으로: 날짜, 크게 쓴 시각, 앰버 D-day, 내 답 |
| 색 쓰는 법 | 앰버는 주요 버튼·현재 탭·D-day·로고의 "몽"에만. 내 채팅 말풍선은 잉크 |
| 글꼴 | Google Fonts 대신 앱에 싣는다(`@fontsource`) → iOS 앱에서도 오프라인으로 같은 글꼴 |

## 검사 결과

| | 전 | 후 |
|---|---|---|
| Floor(절대 규칙) FAIL | 73 | 0 |
| Reflex(습관적 기본값) | 60 | 0 (예외 2: 목록 행 높이, 로고의 앰버 "몽") |
| 독립 리뷰(서브에이전트) | | 8건 중 7건 해결 |

고친 대표 항목: 이모지 아이콘(알림 🙋📅, 투표 👑) → 아이콘, 가운뎃점으로 이은 정보 줄 → 가는 세로선, "–" → "~",
화살표 붙은 버튼 글자(← 뒤로, 열기 →) → 아이콘, 투명도만으로 표시한 비활성, 대비 부족, 글자 크기 11~12px → 12px 이상,
알림 빨간 점·색 띠 → 굵기와 아이콘 바탕.

바뀐 문구 3곳: 합주 시간 "20:00–22:00" → "20:00~22:00", 참석 수 "참석 2 · 늦음 1 · 불참 0" → 세로선으로 나눔, 정산 안내의 "—" → 마침표.

## 화면 확인 방법 (서버 없이)

```bash
cd frontend
npm run mock        # 가짜 API (8080) - 모든 화면에 예시 데이터
npm run dev         # http://localhost:5173
curl -X POST localhost:8080/__mock/logout   # 로그인 화면 보기
```

전/후 나란히 보기: `frontend/.hallmark/compare.html` (로컬에서 Hallmark를 다시 돌리면 생김)
